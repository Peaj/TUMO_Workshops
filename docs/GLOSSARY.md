# Glossar: Deutsch im Workshop

Die deutsche TUMO-Seite übersetzt Fachbegriffe zu wörtlich. In der Spielebranche und in
Unity sind die englischen Begriffe üblich, also bleiben sie englisch. Unity selbst läuft
auf Englisch: alles, was die Teens im Editor sehen (Menüs, Fenster, Komponenten,
Werkzeuge), wird genau so geschrieben wie im Editor.

## Grundregeln

- Fachbegriffe, Unity-Begriffe und Berufsbezeichnungen bleiben englisch
  (Game Designer, Level Designer, Artist, Developer).
- Englische Substantive werden großgeschrieben und bekommen einen deutschen Artikel
  ("das Prefab", "die Scene", "der Inspector").
- Normale Alltagssprache bleibt deutsch (Aufgabe, erklären, zeigen, speichern).
- Die Teilnehmenden heißen "Teens".
- Wenn die deutschen Folien einen schlecht übersetzten Begriff zeigen, den die Teens
  auf dem Beamer sehen, steht das in der `note` ("Folie sagt 'Spielebenen'").

## Bekannte Übersetzungsfehler

| Englisch        | TUMO-Deutsch (falsch)   | Wir schreiben    |
| --------------- | ----------------------- | ---------------- |
| Game Level      | Spielebenen             | Game Level       |
| Level           | Ebene                   | Level            |
| 3Cs             | 3Ks                     | 3Cs              |
| Vertex Snap     | Scheitelpunkt-Werkzeug  | Vertex Snap      |
| Command (key)   | Befehl                  | CMD              |
| Instance        | Klon                    | Instanz          |

## Weitere Begriffe, die englisch bleiben

Asset, Prefab, Scene, GameObject, Component, Inspector, Hierarchy, Project Window,
Scene View, Game View, Play Mode, Transform, Terrain, Material, Texture, Collider,
Rigidbody, Character Controller, Player, Controller, Camera, Gameplay, Game Design,
Level Design, Blockout, Landmark, Checkpoint, Spawn Point, Directional Light,
Point Light, Spot Light, Skybox, Snapping, Pivot, Gizmo, Build, Feedback, Playtest,
Show and Tell, Google Classroom.

Neue Fälle, die beim Schreiben auffallen, werden in die Tabelle oben eingetragen.
